# 🧮 Calculator App

A simple and user-friendly Calculator Application developed as part of my **SkillCraft Technology Internship**. This project is designed to perform basic mathematical operations through an interactive and easy-to-use interface.

## 📌 Project Overview

The Calculator App provides a convenient way to perform everyday mathematical calculations. It focuses on simplicity, functionality, and an intuitive user experience.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 User-friendly calculator interface
- ⚡ Instant calculation results
- 🎯 Simple and intuitive design
- 🧮 Supports basic arithmetic operations
